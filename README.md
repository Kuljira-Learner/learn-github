# learn-github
สวัสดีค่ะทุกคน! สรุปการเดินทางก้าวแรกในสายวิชาชีพค่ะ 🎓✨
ดิฉันจบการศึกษาจากคณะบัญชี มหาวิทยาลัยบูรพา ตอนนี้กำลังมองหาโอกาสงานในตำแหน่ง ผู้ช่วยผู้สอบบัญชี (Junior Auditor / Audit Assistant) เพื่อเก็บชั่วโมงและสานฝันสู่การเป็น CPA ค่ะ
ในช่วงที่ผ่านมา ดิฉันได้สะสมประสบการณ์ผ่านการฝึกงาน 2 ด้านหลักๆ:
💼 ด้านการตรวจสอบบัญชี (6 เดือน): ตรวจสอบงบการเงินตามมาตรฐาน TFRS for NPAEs ครอบคลุม 5 ธุรกิจ (Trading, Service, Consulting, Manufacturing, Transportation)
📝 ด้านการทำบัญชีและภาษี: รับผิดชอบการบันทึกบัญชี, ยื่นภาษีประจำเดือน (VAT, WHT) และภาษีครึ่งปี (ภ.ง.ด.51)
ดิฉันพร้อมนำความรู้ ความเข้าใจในธุรกิจที่หลากหลาย และความตั้งใจจริง มาเริ่มงานและเติบโตไปพร้อมกับทีม ค่ะ หากบริษัทใดกำลังเปิดรับสมัคร สามารถติดต่อหรือส่งข้อมูลมาได้เลยนะคะ ยินดีที่ได้ทำความรู้จักกับพี่ๆ เพื่อนๆ ในสายงานทุกคนค่ะ
